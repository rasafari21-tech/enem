# 📚 Plano ENEM 2027

Aplicación web interactiva y planificador de estudio para la preparación del **ENEM 2027** (Exame Nacional do Ensino Médio).

🌐 **Acceso web en vivo:** [https://rasafari21-tech.github.io/enem/](https://rasafari21-tech.github.io/enem/)

---

## 🎯 Características principales

- **Cronograma interactivo semanal:** Planificación detallada semana por semana dividida en bloques diarios (12:00–13:30 y 17:30–19:00).
- **Método «bus + casa»:** en el bus (sin internet) se lee el paquete preparado por la IA y se responde de cabeza; en casa (wifi + cuaderno) la IA corrige solo con pistas y trae preguntas reales del ENEM.
- **Prompts ya rellenados por bloque:** paquete offline, corrección, refuerzo y redacción; las respuestas y los errores guardados se insertan solos.
- **Repaso espaciado automático:** cada paquete incluye preguntas de temas antiguos y de los errores guardados.
- **Registro de Progreso y Métricas:** Seguimiento de bloques completados, horas de sueño, porcentajes de aciertos por área y notas TRI estimadas.
- **Banco de Prompts para IA:** Plantillas para explicación socrática, tutoría paso a paso y corrección de redacciones bajo las 5 competencias del ENEM.
- **Diseño Móvil Optimizado:** Soporte WebApp / PWA para agregar a la pantalla de inicio en smartphones y tablets.

## 🚀 Uso local

Para abrir la aplicación localmente:
1. Clona el repositorio:
   ```bash
   git clone https://github.com/rasafari21-tech/enem.git
   ```
2. Abre `index.html` en cualquier navegador web.
